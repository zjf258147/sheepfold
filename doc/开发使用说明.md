# IMS 开发使用说明

## 一、启动方式

### 方式一：开发模式（推荐日常开发）

前后端分别启动，支持热更新，修改代码后刷新浏览器即可看到效果。

#### 1. 启动后端（端口 8000）

```bash
cd ims-main/backend

# 首次运行需先安装依赖
uv sync

# 配置环境变量（从模板复制）
cp .env.example .env
# 编辑 .env，修改数据库连接信息

# 执行数据库迁移
uv run alembic upgrade head

# 启动后端服务
uv run uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

后端启动成功后，可以看到：
```
INFO:     Uvicorn running on http://0.0.0.0:8000
```

#### 2. 启动前端（端口 5173）

```bash
cd ims-main/frontend

# 首次运行需先安装依赖
npm install

# 启动前端开发服务器
npm run dev
```

前端启动成功后，可以看到：
```
VITE v5.x.x  ready in xxx ms
➜  Local:   http://localhost:5173/
```

#### 3. 浏览器访问

打开浏览器，访问：**`http://localhost:5173`**

> 前端 Vite 开发服务器会自动将 `/api` 请求代理到后端 `http://127.0.0.1:8000`，无需额外配置。

---

### 方式二：Docker Compose 部署（完整环境）

一键启动 MySQL + 后端 + 前端，适合完整验证。

```bash
cd ims-main

# 配置环境变量（从模板复制）
cp .env.example .env

# 启动所有服务
docker compose up -d

# 查看运行状态
docker compose ps
```

浏览器访问：**`http://localhost:8080`**

| 服务 | 端口 | 说明 |
|------|------|------|
| 前端 (Nginx) | 8080 | 浏览器访问入口 |
| 后端 (FastAPI) | 8000 | API 服务 + Swagger 文档 |
| 数据库 (MySQL) | 3306 | 数据存储 |

## 四、常用命令

```bash
# 启动全部服务
docker compose up -d

# 停止全部服务
docker compose down

# 仅启动后端开发
cd ims-main/backend && uv run uvicorn main:app --reload --host 0.0.0.0 --port 8000

# 仅启动前端开发
cd ims-main/frontend && npm run dev

# 数据库迁移
cd ims-main/backend && uv run alembic upgrade head

# 数据库备份
docker exec ims-db mysqldump -u root -p ims > backup_$(date +%Y%m%d_%H%M%S).sql

# 查看 Git 提交记录
git log --oneline -5
```

## 五、开发完成后验证

每完成一个功能点，在浏览器中验证：

1. 打开 `http://localhost:5173`（开发模式）或 `http://localhost:8080`（Docker 模式）
2. 使用 `admin` / `admin123` 登录
3. 进入对应功能页面，确认界面显示正常
4. 执行新增/编辑/删除等操作，确认功能正常
5. 检查数据库是否有对应记录
6. 检查审计日志是否记录了操作

## 六、常见问题

> **完整问题排查记录**：见 `doc/开发环境问题记录.md`，记录了环境搭建过程中遇到的 9 个问题及解决方案。

### Q: 前端页面空白或 API 请求失败？
- 确认后端已启动且端口 8000 可访问
- 检查 `frontend/vite.config.js` 中代理目标地址是否正确
- 打开浏览器开发者工具（F12）查看 Network 面板错误信息

### Q: 数据库连接失败？
- 确认 MySQL 服务已启动
- 检查 `backend/.env` 中数据库配置是否正确
- 尝试用 `mysql -u root -p` 命令行连接测试

### Q: 端口被占用？
```bash
# Windows 查看端口占用
netstat -ano | findstr :8000
netstat -ano | findstr :5173

# 修改后端端口：编辑 backend/.env 中的 PORT
# 修改前端端口：编辑 frontend/vite.config.js 中的 server.port
```

### Q: uv 未安装？
```bash
# 替代方案：使用标准 Python 命令
python -m uvicorn main:app --reload --host 0.0.0.0 --port 8000
python -m alembic upgrade head
```

### 首次初始化（仅首次）

```bash
# 创建数据库和用户
mysql -u root -p123456 -e "
CREATE DATABASE IF NOT EXISTS ims CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER IF NOT EXISTS 'ims'@'%' IDENTIFIED BY 'ims_pass';
CREATE USER IF NOT EXISTS 'ims'@'localhost' IDENTIFIED BY 'ims_pass';
GRANT ALL PRIVILEGES ON ims.* TO 'ims'@'%';
GRANT ALL PRIVILEGES ON ims.* TO 'ims'@'localhost';
FLUSH PRIVILEGES;
"

# 创建管理员账号
python -c "
import bcrypt
salt = bcrypt.gensalt()
hashed = bcrypt.hashpw('admin123'.encode('utf-8'), salt)
print(hashed.decode('utf-8'))
"
# 将输出的 hash 值插入 sys_user 表
```
