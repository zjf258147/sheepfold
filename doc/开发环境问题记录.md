## 问题4：MySQL 服务无法注册为 Windows 服务

**日期**：2026-09-04

**现象**：`mysqld --install MySQL57` 报 `Install/Remove of the Service Denied!`。

**根因**：当前 PowerShell 没有管理员权限，无法注册 Windows 系统服务。

**解决方案**：直接前台启动 mysqld 进程，不注册为服务。

**涉及命令**：
```bash
& 'C:\Program Files\MySQL\MySQL Server 5.7\bin\mysqld.exe' --defaults-file='C:\ProgramData\MySQL\MySQL Server 5.7\my.ini' --console
```

**注意**：每次重启电脑后需要重新执行此命令启动 MySQL。

## 问题5：数据库和用户不存在

**日期**：2026-09-04

**现象**：启动后端时报数据库连接失败。

**根因**：MySQL 中没有 `ims` 数据库和 `ims` 用户。

**解决方案**：
```sql
CREATE DATABASE IF NOT EXISTS ims CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER IF NOT EXISTS 'ims'@'%' IDENTIFIED BY 'ims_pass';
CREATE USER IF NOT EXISTS 'ims'@'localhost' IDENTIFIED BY 'ims_pass';
GRANT ALL PRIVILEGES ON ims.* TO 'ims'@'%';
GRANT ALL PRIVILEGES ON ims.* TO 'ims'@'localhost';
FLUSH PRIVILEGES;
```

**涉及命令**：
```bash
mysql -u root -p123456 -e "CREATE DATABASE IF NOT EXISTS ims ..."
```

## 问题8：admin 用户不存在

**日期**：2026-09-04

**现象**：前端登录页面输入 `admin` / `admin123` 后提示"登录失败：用户名不存在"。

**根因**：Alembic 迁移脚本 `db50005be6c8_init_sys_user.py` 只创建了 `sys_user` 表结构，未插入初始管理员数据。

**解决方案**：手动通过 MySQL 插入 admin 用户：
```sql
INSERT INTO sys_user (username, password, nickname, role, status, created_at, updated_at)
VALUES ('admin', '{bcrypt_hash}', '管理员', 'ADMIN', 1, NOW(), NOW());
```

密码使用 bcrypt 加密，通过 Python 生成：
```python
import bcrypt
salt = bcrypt.gensalt()
hashed = bcrypt.hashpw('admin123'.encode('utf-8'), salt)
print(hashed.decode('utf-8'))
```

**预防措施**：后续考虑在 `main.py` 的 lifespan 中添加自动检查并创建 admin 用户的逻辑。

## 问题10：Android SDK 命令行工具安装与版本兼容

**日期**：2026-09-14

**现象**：通过 winget 安装 Microsoft OpenJDK 17 后，下载 Android cmdline-tools 最新版（11076708），运行 `sdkmanager.bat` 报错：
```
错误: 找不到或无法加载主类 com.android.sdklib.tool.sdkmanager.SdkManagerCli
```

**根因**：
1. cmdline-tools 最新版（11076708）与 JDK 17 存在兼容性问题，`sdkmanager-classpath.jar` 中的主类无法加载
2. 下载的 zip 解压后目录结构与标准 SDK 布局不一致：`cmdline-tools/cmdline-tools/{bin,lib}` 需要移到 `cmdline-tools/latest/{bin,lib}`

**解决方案**：
1. 改用 cmdline-tools 稳定版（9862592），兼容 JDK 17/21
2. 解压后重新组织目录结构：
   ```powershell
   Expand-Archive -Path "$env:TEMP\cmdline-tools.zip" -DestinationPath "C:\Android\cmdline-tools" -Force
   Copy-Item "C:\Android\cmdline-tools\cmdline-tools\*" "C:\Android\cmdline-tools\latest\" -Recurse -Force
   Remove-Item "C:\Android\cmdline-tools\cmdline-tools" -Recurse -Force
   ```
3. 设置环境变量：`ANDROID_HOME=C:\Android`，`JAVA_HOME` 指向 JDK 路径
4. 通过 `sdkmanager.bat --sdk_root=C:\Android` 安装 SDK 组件

**涉及命令**：
```powershell
$env:JAVA_HOME = "C:\Program Files\Microsoft\jdk-17.0.20.101-hotspot"
$env:ANDROID_HOME = "C:\Android"
& "C:\Android\cmdline-tools\latest\bin\sdkmanager.bat" --sdk_root="C:\Android" "platforms;android-36" "build-tools;36.0.0" "platform-tools"
```

**状态**：✅ 已解决（SDK API 36 + build-tools 36.0.0 + platform-tools 安装完成）

## 问题11：Gradle 8.14.3 从官网下载极慢

**日期**：2026-09-14

**现象**：首次运行 `gradlew.bat assembleDebug` 时自动下载 Gradle 8.14.3-all.zip（约 214MB），从 Google 官网下载速度极慢（约 30KB/s），预估需要数小时。

**根因**：Gradle 官方下载站 `services.gradle.org` 在国内访问速度受限，无 CDN 加速。

**解决方案**：
1. 先停止构建，找到正在下载的 `.part` 文件路径：
   ```powershell
   Get-ChildItem "$env:USERPROFILE\.gradle\wrapper\dists\gradle-8.14.3-all" -Recurse | Where-Object { $_.Extension -eq ".part" }
   ```
2. 清理未完成的下载，从腾讯云镜像手动下载：
   ```powershell
   $distDir = Get-ChildItem "$env:USERPROFILE\.gradle\wrapper\dists\gradle-8.14.3-all" -Directory | Select-Object -First 1
   Remove-Item "$distDir\*" -Recurse -Force
   Invoke-WebRequest -Uri "https://mirrors.cloud.tencent.com/gradle/gradle-8.14.3-all.zip" -OutFile "$distDir\gradle-8.14.3-all.zip"
   ```
3. 下载完成后重新运行 `gradlew.bat assembleDebug`，Gradle 会自动解压并跳过下载步骤

**涉及命令**：见上

**状态**：✅ 已解决（腾讯镜像下载完成，214MB）

## 问题12：JDK 21 安装 — Capacitor 8 编译要求

**日期**：2026-09-14

**现象**：构建 `app-debug.apk` 时 `capacitor-camera` 模块编译失败，Gradle toolchain 要求 JDK 21。

**根因**：Capacitor 8.x 插件（特别是 `capacitor-camera` 的 AAR 编译）内建 Gradle Java toolchain 检测，指定 `languageVersion=21`。项目使用的 JDK 17 不满足要求。

**解决方案**：
1. 保留 JDK 17（后端开发使用），额外安装 JDK 21：
   ```bash
   winget install --id Microsoft.OpenJDK.21 --accept-source-agreements --accept-package-agreements --silent
   ```
2. JDK 21 安装路径：`C:\Program Files\Microsoft\jdk-21.0.12.101-hotspot`
3. 构建 APK 时将 `JAVA_HOME` 切换为 JDK 21：
   ```powershell
   $env:JAVA_HOME = "C:\Program Files\Microsoft\jdk-21.0.12.101-hotspot"
   ```

**环境架构**：
| 用途 | JDK 版本 | Path |
|------|----------|------|
| 后端开发 (FastAPI) | JDK 17 | `C:\Program Files\Microsoft\jdk-17.0.20.101-hotspot` |
| Android 构建 (Capacitor) | JDK 21 | `C:\Program Files\Microsoft\jdk-21.0.12.101-hotspot` |

**状态**：✅ 已解决（JDK 17 + JDK 21 共存）

## 问题13：Capacitor APK 构建完整流程（从头搭建）

**日期**：2026-09-14

**现象**：开发机上无 Android SDK、无 JDK、无 Gradle，需要从零搭建 Capacitor Android 构建环境。

**根因**：开发机原本用于 Python/Vue 开发，未安装 Android 开发工具链。

**解决方案（完整流程）**：

**步骤1**：安装 JDK 17（后端开发用）和 JDK 21（Android 构建用）
```bash
winget install --id Microsoft.OpenJDK.17 --accept-source-agreements --accept-package-agreements --silent
winget install --id Microsoft.OpenJDK.21 --accept-source-agreements --accept-package-agreements --silent
```

**步骤2**：下载并配置 Android 命令行工具（免 Android Studio）
```powershell
# 创建 SDK 目录
New-Item -ItemType Directory -Force -Path "C:\Android\cmdline-tools"

# 下载 cmdline-tools（稳定版 9862592）
Invoke-WebRequest -Uri "https://dl.google.com/android/repository/commandlinetools-win-9862592_latest.zip" -OutFile "$env:TEMP\cmdline-tools.zip"

# 解压并重组目录结构（cmdline-tools/cmdline-tools/* → cmdline-tools/latest/*）
Expand-Archive -Path "$env:TEMP\cmdline-tools.zip" -DestinationPath "C:\Android\cmdline-tools" -Force
Copy-Item "C:\Android\cmdline-tools\cmdline-tools\*" "C:\Android\cmdline-tools\latest\" -Recurse -Force
Remove-Item "C:\Android\cmdline-tools\cmdline-tools" -Recurse -Force
```

**步骤3**：安装 Android SDK 组件（API 36 + Build Tools + Platform Tools）
```powershell
$env:JAVA_HOME = "C:\Program Files\Microsoft\jdk-17.0.20.101-hotspot"
$env:ANDROID_HOME = "C:\Android"
& "C:\Android\cmdline-tools\latest\bin\sdkmanager.bat" --sdk_root="C:\Android" "platforms;android-36" "build-tools;36.0.0" "platform-tools"
```

**步骤4**：创建 `local.properties`（Gradle 需要知道 SDK 路径）
```properties
# ims-main/frontend/android/local.properties
sdk.dir=C\:\\Android
```

**步骤5**：配置 Gradle（非 ASCII 路径 + 腾讯镜像加速）
```properties
# ims-main/frontend/android/gradle.properties 追加
android.overridePathCheck=true
```

**步骤6**：下载 Gradle 8.14.3（腾讯镜像）
```powershell
$distDir = Get-ChildItem "$env:USERPROFILE\.gradle\wrapper\dists\gradle-8.14.3-all" -Directory | Select-Object -First 1
Invoke-WebRequest -Uri "https://mirrors.cloud.tencent.com/gradle/gradle-8.14.3-all.zip" -OutFile "$distDir\gradle-8.14.3-all.zip"
```

**步骤7**：构建 APK
```powershell
$env:JAVA_HOME = "C:\Program Files\Microsoft\jdk-21.0.12.101-hotspot"
$env:ANDROID_HOME = "C:\Android"
cd ims-main/frontend/android
.\gradlew.bat assembleDebug --build-cache
```

**构建结果**：
| 项目 | 值 |
|------|-----|
| 构建时长 | 4分42秒 |
| Tasks | 187（159 executed, 28 from cache） |
| APK大小 | 20.3 MB |
| APK类型 | debug（未签名） |
| 产物路径 | `android/app/build/outputs/apk/debug/app-debug.apk` |

**状态**：✅ 已解决（APK 构建成功）

**预防措施**：
- 将 `local.properties` 加入 `.gitignore`（机器特定配置，不应提交）
- `gradle.properties` 中 `android.overridePathCheck=true` 已加入提交（解决中文路径问题）
- 推荐新项目使用全英文路径避免此类问题
