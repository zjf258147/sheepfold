# 权限改造 — 检测项目清单

> 版本：v1.0 | 制定日期：2026-09-20 | 状态：待执行
>

## 执行顺序（按逻辑依赖排列）

```
第0步 → 代码基线检查（确认当前权限状态，记录改造前基线）

第2步 → 后端 API 改造（逐模块加 require_permission）
第3步 → 后端权限矩阵测试（参数化测试，6角色×所有写接口）
第4步 → 前端权限字典冻结（permissions.js 创建并校验）
第5步 → 前端 auth.canEdit 实现
第6步 → 前端 PermissionButton 组件
第7步 → 前端菜单全开

第9步 → 前端单元测试
第10步 → 手动验收
第11步 → 回归测试
```
