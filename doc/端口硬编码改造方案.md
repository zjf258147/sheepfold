## 一、问题诊断

| # | 问题 | 根因 |
|---|------|------|
| 1 | 前端端口变来变去（5173→5174→5175→5176） | Vite 默认行为：5173 被占则静默漂移到下一个可用端口 |
| 2 | 端口变了前端就废了 | 后端 CORS 白名单只允许 5173，漂移端口被 CORS 拦截 |
| 3 | 全项目 67 处硬编码 | vite.config、config.py、E2E测试、路由遍历脚本、文档 |

## 二、修复策略

```
核心思路：不阻止 Vite 端口漂移，而是让 CORS 自适应任意端口。

┌─────────────────────────────────────────────────────┐
│  Vite 端口漂移  →  CORS allow_origin_regex 兜底    │
│  (strictPort:false)    (正则匹配任意开发端口)       │
│                                                     │
│  测试脚本  →  E2E_BASE_URL 环境变量                │
│  用户感知  →  Vite 端口提示插件                     │
│  端口占用  →  check_port.ps1 检查工具               │
└─────────────────────────────────────────────────────┘
```

## 四、批次①：配置层（3 文件）

### 4.1 `vite.config.js`

```diff
server: {
  host: '0.0.0.0',
  port: 5173,
- // Vite 静默漂移，无提示
+ strictPort: false,  // 允许漂移，靠 CORS 正则兜底
  proxy: { ... },
},
+ plugins: [
+   vue(),
+   {
+     name: 'port-logger',
+     configureServer(server) {
+       server.httpServer?.once('listening', () => {
+         console.log(`\n  ✅ 前端运行在: http://localhost:${server.config.server.port}\n`)
+       })
+     }
+   },
+   AutoImport(...),
+   Components(...),
+ ],
```

### 4.2 `config.py`

```diff
 CORS_ORIGINS: str = "http://localhost:5173"
+ CORS_ORIGIN_REGEX: str = r"http://(localhost|127\.0\.0\.1):\d+"
```

### 4.3 `main.py`

```diff
 app.add_middleware(
     CORSMiddleware,
-    allow_origins=settings.cors_origins_list,
+    allow_origins=settings.cors_origins_list if not settings.DEBUG else [],
+    allow_origin_regex=settings.CORS_ORIGIN_REGEX if settings.DEBUG else None,
     allow_credentials=True,
     allow_methods=["*"],
     allow_headers=["*"],
 )
```

**逻辑说明**：

| 环境 | `allow_origins` | `allow_origin_regex` | 效果 |
|------|:---:|:---:|------|
| DEBUG=True | `[]`（空） | 正则匹配 | 任意本地端口通过 |
| DEBUG=False | 白名单列表 | `None` | 仅白名单域名通过 |

## 六、批次③：端口检查工具（1 文件）

新建 `scripts/check_port.ps1`：

```powershell
param([int]$Port = 5173)

$ErrorActionPreference = "Stop"

$conn = Get-NetTCPConnection -LocalPort $Port -ErrorAction SilentlyContinue
if ($conn) {
    Write-Host "  ❌ 端口 $Port 已被占用" -ForegroundColor Red
    Write-Host "  进程名: $((Get-Process -Id $conn.OwningProcess).ProcessName)" -ForegroundColor Yellow
    Write-Host "  PID: $($conn.OwningProcess)" -ForegroundColor Yellow
    Write-Host ""
    Write-Host "  释放端口: taskkill /PID $($conn.OwningProcess) [/F]" -ForegroundColor Cyan
    exit 1
}
Write-Host "  ✅ 端口 $Port 可用" -ForegroundColor Green
exit 0
```
