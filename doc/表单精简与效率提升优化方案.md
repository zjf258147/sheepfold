# IMS 表单精简与效率提升优化方案

> 版本：v1.0  
> 日期：2026-09-18  
> 状态：待实施

---

## 一、项目现状：时间筛选器盘点

系统当前共 **8 个页面** 使用了 `el-date-picker type="daterange"`，但均未配置快捷选择：

| # | 页面文件 | 筛选字段 | 用途 |
|---|----------|----------|------|
| 1 | `Inbound.vue` | `query.dateRange` | 入库单创建时间 |
| 2 | `Outbound.vue` | `query.dateRange` | 出库单创建时间 |
| 3 | `Shipment.vue` | `query.dateRange` | 发货日期 |
| 4 | `RmaReturn.vue` | `query.dateRange` | 退货日期 |
| 5 | `IncomingReceipt.vue` | `query.dateRange` | 收货日期 |
| 6 | `Settings.vue` | `auditQuery.dateRange` | 审计日志时间 |
| 7 | `SnapshotLedger.vue` | `ledgerQuery.dateRange` | 库存流水日期 |
| 8 | `SnapshotStatistics.vue` | `summaryQuery.dateRange` | 快照汇总区间 |

其中 `SnapshotLedger.vue` 和 `SnapshotStatistics.vue` 已有默认时间范围（最近7天），其余 6 个页面无默认时间、无快捷选择。

## 二、优化方案一：统一添加快捷时间选择（P0）

### 2.1 实现方式

在 `src/utils/datetime.js` 中创建公共 `dateRangeShortcuts`，所有页面引用，避免重复代码。

普通页面（end = 今天）：

```js
// src/utils/datetime.js 末尾新增
export const dateRangeShortcuts = [
  {
    text: '最近一周',
    value: () => {
      const end = new Date()
      const start = new Date()
      start.setTime(start.getTime() - 7 * 24 * 60 * 60 * 1000)
      return [start, end]
    },
  },
  {
    text: '最近一个月',
    value: () => {
      const end = new Date()
      const start = new Date()
      start.setMonth(start.getMonth() - 1)
      return [start, end]
    },
  },
  {
    text: '最近半年',
    value: () => {
      const end = new Date()
      const start = new Date()
      start.setMonth(start.getMonth() - 6)
      return [start, end]
    },
  },
  {
    text: '最近一年',
    value: () => {
      const end = new Date()
      const start = new Date()
      start.setFullYear(start.getFullYear() - 1)
      return [start, end]
    },
  },
  {
    text: '最近两年',
    value: () => {
      const end = new Date()
      const start = new Date()
      start.setFullYear(start.getFullYear() - 2)
      return [start, end]
    },
  },
]
```

快照页面（end = 昨天，不超今天）：

### 2.2 各页面应用

每个页面的 `el-date-picker` 添加 `:shortcuts` 属性：

```html
<el-date-picker
  v-model="query.dateRange"
  type="daterange"
  range-separator="至"
  start-placeholder="开始日期"
  end-placeholder="结束日期"
  value-format="YYYY-MM-DD"
  :shortcuts="dateRangeShortcuts"
  style="width:260px"
/>
```

### 2.3 各模块建议默认时间范围

| 模块 | 页面 | 默认值 | 理由 |
|------|------|--------|------|

| 出库管理 | Outbound.vue | 近一月 | 同上 |
| 出货管理 | Shipment.vue | 近一月 | 同上 |
| 返厂维修 | RmaReturn.vue | 近三月 | 维修周期较长 |
| 来料管理 | IncomingReceipt.vue | 近一月 | 同上 |
| 审计日志 | Settings.vue | 近一周 | 关注近期操作 |
| 库存流水 | SnapshotLedger.vue | 近一周（已有） | 保持 |
| 快照汇总 | SnapshotStatistics.vue | 近一周（已有） | 保持 |

## 三、优化方案二：必填项精简（P0）

### 3.1 全局精简原则

| 原则 | 说明 |
|------|------|
| 能自动带出的不手填 | 选SKU → 名称/规格/单位自动填充 |
| 能系统生成的不手填 | 单号、时间戳、创建人自动生成 |
| 能默认的不手选 | 日期默认当天，状态默认初始值 |
| 能联动的分级填 | 选成品→带出BOM→带出物料清单 |

### 3.2 各表可精简字段清单

| 表 | 当前必填 | 可改为 | 理由 |
|----|---------|--------|------|
| `incoming_receipt` | `batch_no` | 选填 | 非所有物料都有批次号 |
| `incoming_receipt` | `delivery_date` | 默认当天 | 不用手选 |
| `incoming_receipt` | `unit` | 自动带出 | 从SKU带出 |
| `incoming_inspection` | `sample_qty` | 选填 | 全检时不需要 |
| `incoming_inspection` | `defect_qty` | 选填 | 合格时不需要 |
| `incoming_inspection` | `inspection_no` | 系统生成 | 自动生成 |
| `rma_repair` | `repair_no` | 系统生成 | 自动生成WX |
| `rma_repair` | `old_sn` | 自动带出 | 从返厂单带出 |
| `shipment` | `sku_code`/`sku_name`/`spec`/`unit` | 自动带出+只读展示 | 选SKU后带出 |
| `bom_detail` | `material_sku_code`/`name` | 自动带出 | 选物料后带出 |
| `bom_header` | `product_sku_code`/`name` | 自动带出 | 选成品后带出 |
| `stocktake` | `started_at` | 系统生成 | 自动记录 |

> **注意**：标为"选填"或"自动带出"的字段如涉及数据库 `NOT NULL` 约束或后端 Pydantic Schema 必填校验，需**前后端同步修改**。

### 3.3 具体页面的字段精简

#### Shipment.vue —— 最多可精简4个字段 + 3个折叠

**问题**：当前14个字段，其中4个是自动带出且只读的：

- `sku_code`、`sku_name`、`spec`、`unit`

**建议**：

1. 将这4个只读字段合并为一行紧凑展示（`物料编码 | 名称 | 规格 | 单位`），减少表单高度一半
2. 将 `u9_task_no`、`tf_version`、`host_version` 放入"技术参数（可选）"折叠面板，默认折叠

#### Inbound.vue —— `unit_price` 字段

**问题**：`unit_price`（单价）在退货入库、调拨入库等场景不适用。

**建议**：仅在"采购入库"模式下显示，其他模式默认隐藏。

#### Customer.vue —— 表单分组折叠

**问题**：10个字段平铺，视觉负担重。

**建议**：拆为两个区块：

- **基本信息**（必填）：`name`、`contact_person`、`contact_phone`
- **合同与扩展**（可折叠）：`contract_no`、`contract_start`、`contract_end`、`address`、`contact_email`、`weight`、`remark`

#### RmaReturn.vue —— 减少冗余

**问题**：7个弹窗表单，部分字段重复。

**建议**：

- `diagnosisForm.change_reason` 和 `repairForm.change_reason` 可统一为顶层"备注/原因"区域
- 维修不换SN时，`new_sn` 默认等于 `old_sn`，不用重复填写

#### DeviceLedger.vue —— `software_version`

**建议**：移至表单底部或折叠区域，默认收起。

## 四、优化方案三：其他提效项（P1-P3）

### 4.1 筛选条件记忆（P1）

用户在页面间切换后筛选条件丢失。建议用 `localStorage` 保存各页面的 `query`：

```js
// composables/useFilterPersist.js
// query 变化 → 自动存入 localStorage
// 页面 mounted → 自动恢复
```

> **注意**：快捷时间选择恢复时，需判断是否为快捷选项，如果是则按相对时间重新计算，避免过期数据。

### 4.2 表单自动保存草稿（P1）

填写中途意外关闭，重开自动恢复。

> **注意**：多标签场景需按"单据ID"或"操作类型"做 key 隔离，避免互相覆盖。

### 4.3 常用选项置顶（P1）

下拉选项按使用频率排序（如供应商、物流商、物料）。

### 4.4 历史记录复用（P1）

上次填的供应商/客户/物流商，下次默认选中。

### 4.5 扫码连续录入（P1）

扫一个自动追加一行，不用重复点击。适用于入库SN、出货SN、盘点SN。

> **注意**：需防重复——同一SN扫两次应自动去重并提示，而非静默添加两条。

### 4.6 弹窗自动聚焦（P2）

所有创建/编辑弹窗打开后自动聚焦第一个输入框，减少鼠标点击。

### 4.7 表格列配置（P2）

支持列显示/隐藏，低频列（如 `TF版本`、`上位机版本`）默认隐藏。

### 4.8 批量操作增强（P2）

当前 Shipment 已支持批量打印，建议补充：

- 入库单/出库单 → 批量提交审核
- 入库单/出库单 → 批量导出
- 批量打印

### 4.9 SKU选择器增强（P2）

- 最近使用的 SKU 置顶
- 支持按分类筛选后显示（已有部分实现）

### 4.10 一键复制创建（P2）

复制已有记录快速创建新记录（如相似的出货单、BOM）。

### 4.11 模板功能（P3）

常用配置（如常用物料组、常用物流配置）保存为模板。

### 4.12 表单分步填写（P3）

长表单拆成2-3步，降低心理负担。

### 4.13 全局搜索快捷键（P3）

增加 `Ctrl+K` 全局搜索入口。
