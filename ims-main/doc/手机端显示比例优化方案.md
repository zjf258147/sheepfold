# 手机端显示比例优化方案

> 版本：v1.0 | 日期：2026-09-15 | 状态：已执行 ✅

## 一、问题定位

App 登录后整体显示比例不佳，主要表现为：弹窗溢出屏幕、表格横向挤压、表单 label 和输入框挤在一行、按钮偏小不易点击。

## 二、调研结论

| 组件 | 出现次数 | 涉及文件 | 方案 |
|------|:---:|:---:|------|
| `el-dialog` | 70 处 | 15 文件 | 全局 CSS → `width: 96%` |
| `el-table` | 614 处 | 24 文件 | 全局 CSS → `overflow-x: auto` |
| `el-form` | 653 处 | 21 文件 | 全局 CSS → label 上下布局 |
| `el-button` | — | — | 全局 CSS → `min-height: 44px` |
| 侧边栏 | — | 1 文件 | ✅ 已有抽屉式适配，无需改 |
| viewport | — | 1 文件 | ✅ 已有，新增 `viewport-fit=cover` |

**方案**：全局 CSS 方案，不动业务代码，只在 `src/style.css` 加一层 `@media (max-width: 768px)` 样式。

## 三、执行改动

### 3.1 `frontend/src/style.css` — 新增 ~130 行移动端全局样式

| 类别 | 规则 | 效果 |
|------|------|------|
| **弹窗** | `.el-dialog { width: 96% !important }` | 不溢出屏幕 |
| **弹窗内边距** | `.el-dialog__body { padding: 12px }` | 内容更紧凑 |
| **表格** | `.el-table__header-wrapper, .el-table__body-wrapper { overflow-x: auto }` | 可横向滑动 |
| **表格单元格** | `.el-table .cell { padding: 0 8px; white-space: nowrap }` | 不换行、可滑动 |
| **表单布局** | `.el-form-item { display: block }` + label 独立一行 | 上下布局 |
| **搜索表单** | `.el-form--inline .el-form-item { display: block }` | 纵向排列 |
| **按钮** | `.el-button { min-height: 44px; min-width: 44px }` | 触摸友好 |
| **菜单项** | `.el-menu-item { min-height: 48px }` | 触摸友好 |
| **分页** | 隐藏 `sizes` 和 `jump` | 简化显示 |
| **输入框** | `.el-input__inner { font-size: 16px }` | 防 iOS 缩放 |
| **确认框** | `.el-message-box { width: 90%; max-width: 360px }` | 不溢出 |
| **标签页** | `.el-tabs__item { min-height: 44px }` | 触摸友好 |
| **卡片** | `.el-card { margin-bottom: 8px; padding: 8px }` | 紧凑布局 |
| **基础** | `body { font-size: 14px }` | 统一字体 |

### 3.2 `frontend/index.html` — 异形屏适配

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0, maximum-scale=10.0, user-scalable=yes, viewport-fit=cover">
```

新增 `viewport-fit=cover`，适配 iPhone X+ 刘海屏。

### 3.3 `frontend/android/.../AndroidManifest.xml` — 摄像头权限

```xml
<uses-permission android:name="android.permission.CAMERA" />
```

修复扫码提示"原生扫码未识别"问题。

## 五、技术要点

- 所有规则在 `@media (max-width: 768px)` 内，**PC 端零影响**
- Element Plus 表格需要滚动的不是外层 `el-table`，而是内层 `el-table__header-wrapper` 和 `el-table__body-wrapper`
- `!important` 用于覆盖 Element Plus 组件内部默认样式
- `-webkit-overflow-scrolling: touch` 保证 iOS 平滑滚动
- iOS 输入框 `font-size: 16px` 防止 Safari 自动缩放
