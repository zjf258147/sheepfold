1.1 公司信息
项目	内容

1.2 项目概况
我们的项目是一个生产物料与产品追溯管理系统，已完成以下四大主线的功能开发：

主线	名称	核心功能
主线A	采购来料管理	到货登记 → 来料检验 → 合格入库 / 退货供应商
主线B	成品返厂维修管理	退货登记 → 诊断 → 维修换新SN → 报废审批 → 再出货
主线C	出货管理	出货登记 → 关联U9任务单 → 物流信息
主线D	BOM & 生产准备管理	BOM导入/导出 → 库存对比 → 缺料采购建议
当前现状：

✅ 所有业务数据已可通过系统录入、查询、编辑

✅ 数据可导出为 Excel 文件

✅ 数据可导入（批量录入）

❌ 尚不支持专业的打印功能

需求目标：为系统增加 6 种对外单据的专业打印功能，展示公司专业形象。

二、技术方案（已确认：方案B）
2.1 技术选型
选型结论：**方案B — 纯 HTML/CSS 打印组件**（不使用 Vue Print Designer）

| 考量 | 分析 |
|------|------|
| 模板数量 | 只有 6 种固定模板，不需要可视化设计器 |
| 修改频率 | 设计原则已固化（P1-P13），短期内不会频繁变动 |
| 维护成本 | 纯组件 + 打印 CSS 无需额外依赖，任何前端开发都能改 |
| 学习成本 | 团队现有 Vue 3 + Element Plus 技能直接覆盖 |

技术栈：Vue 3 + Element Plus + CSS @media print（与现有项目完全一致，无额外依赖）

2.2 集成方式
- 在 `frontend/src/print/` 下创建打印组件目录
- 每种单据对应一个 Vue 打印模板组件
- 在各业务**列表页表格行**增加"打印"按钮（不建独立详情页）
- 点击打印 → 弹出全屏预览弹窗 → 渲染模板 + 数据 → 打印/导出PDF

2.3 打印工作流程
text
[业务人员]
    ↓
在列表页点击某行的「打印」按钮
    ↓
系统调用后端 API 获取完整打印数据
    ↓
弹出全屏打印预览弹窗（90%宽 × 90vh高）
    ↓
弹窗内渲染对应模板（Vue组件 + CSS @media print）
    ↓
点击「打印」→ 浏览器打印（自动隐藏UI元素）
点击「导出PDF」→ 浏览器另存为PDF
    ↓
关闭弹窗，返回列表页

3.2 统一设计原则（6种单据通用）
P1：品牌区
顶部 25-30mm 区域

从左到右：公司名称（文字商标） → 单据标题 → 单据编号/二维码

公司名称显示格式：

第一行：西安敦临计量检测有限公司（全称，加粗）

第二行：敦临计量（简称，较小字号，灰色）

P2：主色调
主色：深蓝色 #1A3C6E

仅用于标题栏、分割线、表头背景色

禁用彩色、渐变色、花哨装饰

P3：字体
全部使用 宋体（SimSun）

单据标题：22px / 加粗 / 居中

表头字段（单号/日期等）：10px / 常规

表格表头：11px / 加粗 / 居中

表格正文：10px / 常规

P4：三段式布局
text
┌─────────────────────────────────────┐
│  【头部】品牌 + 标题 + 元数据        │  ← 顶部 1/4
├─────────────────────────────────────┤
│  【体部】明细数据表格                │  ← 中部 1/2
│                                      │
├─────────────────────────────────────┤
│  【尾部】合计 + 签名 + 页码          │  ← 底部 1/4
└─────────────────────────────────────┘
P5：表格列序
统一为：序号 → 物料编码 → 物料名称 → 规格型号 → 数量 → 单位 → 备注

P6：金额显示
凡涉及金额，同时显示：

阿拉伯数字：如 ¥1,234.56

中文大写：如 壹仟贰佰叁拾肆元伍角陆分

P7：单据编号
唯一编号，格式统一为：[前缀]-[YYYYMMDD]-[序号]

各单据前缀：

单据	前缀
采购收货单	CG
来料检验报告	JC
退货单	TH
出货单	SH
维修工单	WX
BOM清单	BOM
示例：CG-20260908-001

编号放在单据标题下方或右上角显眼位置

P8：页码
多页时显示：第 X 页 / 共 Y 页

第二页起自动重复表头

P9：分页规则
每页最多 20 行数据

超过自动分页

P10：打印适配
打印时自动隐藏所有按钮、导航栏、侧边栏

仅保留单据内容

P11：签名区
所有对外单据必须有签名区：

我方经办人：签字 + 日期

对方代表：签字 + 日期

签名区底部用虚线分隔

P12：边距
统一：上下 12mm，左右 10mm

适用于 A5 和 A4

P13：公司名称显示
所有单据顶部显示公司全称：西安敦临计量检测有限公司

下方可加简称：敦临计量

无需图片Logo，纯文字商标
