### 3.1 重复代码检测（P0）

### 3.2 代码异味检测（P1）

| # | 检查项 | 说明 |
|---|--------|------|
| 1 | 盘点锁库存逻辑不应放在 API 层 | 放在 Service 层，可复用 |
| 2 | 质保期计算逻辑不应重复 | 提取为 `utils/warranty.py` 工具函数 |
| 3 | DeviceLedger 一对多查询避免 N+1 | 使用 joinedload 或子查询 |
| 4 | 新枚举值添加后检查所有引用 | 确保 switch/match 覆盖所有值 |

### 3.3 安全检查

| # | 检查项 | 说明 |
|---|--------|------|
| 1 | Station/DeviceLedger 操作权限 | 非管理员不能删除场站 |
| 2 | 盘点调整需审批 | 调整确认操作需记录操作人+审计日志 |
| 3 | 轮询接口不暴露敏感信息 | 仅返回未读数量，不含详情 |
| 4 | 内网 App 无需额外安全 | 内网HTTP，JWT认证已有 |
| 5 | SQL注入防护 | 新增API全部使用ORM参数化查询 |

### 3.4 性能检测

| # | 检查项 | 说明 |
|---|--------|------|
| 1 | DeviceLedger 按 SN 查询加索引 | `item_sn` 已有 index |
| 2 | Station 当前设备数统计 | 使用子查询或缓存，避免N+1 |
| 3 | 盘点大批量SN（1000+） | 分页加载，单页不超过100条 |
| 4 | 看板统计接口 | 考虑Redis缓存（TTL=60s） |
| 5 | 轮询接口轻量化 | 单次查询 < 50ms |
