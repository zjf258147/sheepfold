**基类说明**：[db/base.py](file:///c:/Users/25075/Desktop/IMS生产物料与产品追溯管理系统/ims-main/backend/app/db/base.py)

```python
class Base(DeclarativeBase):
    """所有 ORM 模型的基类。"""
    pass

class TimestampMixin:
    """通用时间戳 Mixin：为继承的模型自动添加 created_at / updated_at 字段。"""
    created_at: Mapped[datetime] = mapped_column(...)
    updated_at: Mapped[datetime] = mapped_column(...)
```

> ⚠️ 所有业务模型同时继承 `Base` 和 `TimestampMixin`，因此每个表都自动包含 `id`（自增主键）、`created_at`、`updated_at` 三个字段。

### 2.2.4 数据校验层：`app/schemas/`

每个文件定义对应的 Pydantic 请求/响应模型，文件与 `models/` 和 `api/` 一一对应。

| 文件 | 内容 |
|------|------|
| `auth.py` | 登录请求/响应、Token 模型 |
| `user.py` | 员工创建/更新/列表响应 |
| `product.py` | SKU 创建/更新/列表响应 |
| `inbound.py` | 入库单创建/审核/列表响应 |
| `outbound.py` | 出库单创建/审核/列表响应 |
| `inventory.py` | 库存查询请求/响应 |
| `snapshot.py` | 库存快照/流水请求/响应 |
| ... | 其余文件同理 |

**命名约定**：

| 后缀 | 用途 | 示例 |
|------|------|------|
| `Create` | 创建请求体 | `ProductCreate` |
| `Update` | 更新请求体 | `ProductUpdate` |
| `Response` | 响应体 | `ProductResponse` |
| `ListItem` | 列表项（精简字段） | `ProductListItem` |

### 2.2.9 调用链路

```
HTTP 请求
    │
    ▼
api/xxx.py          ← 路由层：参数校验、权限检查
    │
    ▼

```
