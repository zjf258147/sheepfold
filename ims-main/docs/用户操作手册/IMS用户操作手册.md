# IMS 生产物料与产品追溯管理系统 — 用户操作手册

> **文档版本**：v1.1 | **更新日期**：2026-09-11 | **作者**：文档组

---

## 第0章 通用操作篇

### 0.1 登录与界面

#### 0.1.1 登录系统

1. 打开浏览器，访问系统地址（请联系管理员获取）
2. 输入用户名和密码
3. 点击 **登录** 按钮
4. 登录成功后进入仪表盘页面

> ⚠️ 连续5次密码错误，账号将被临时锁定，请联系管理员解锁。

#### 0.1.2 界面布局说明

系统界面采用经典的后台管理布局：

- **顶部导航栏**：系统名称、用户信息、退出登录
- **左侧菜单栏**：功能模块导航，按角色显示不同菜单
- **主内容区**：当前模块的操作区域
- **底部状态栏**：系统版本信息

#### 0.1.3 首次登录与修改密码

1. 首次登录使用管理员分配的初始密码
2. 点击右上角用户头像 → **修改密码**
3. 输入旧密码、新密码、确认新密码
4. 点击 **保存**
5. 下次登录使用新密码

#### 0.1.4 忘记密码处理

联系系统管理员（`ADMIN` 角色）重置密码。管理员重置后，使用新密码登录，按 0.1.3 步骤修改密码。

### 0.2 通用操作

#### 0.2.1 列表查询

1. 进入功能模块，系统默认显示列表页
2. 在搜索框中输入关键词，按 **回车** 或点击 **搜索**
3. 支持按状态、日期范围等条件筛选
4. 点击 **重置** 清空筛选条件

**SN搜索技巧**：
- 单个SN：直接输入完整SN
- 批量SN：每行一个SN，粘贴后自动识别
- 模糊搜索：输入SN部分内容，系统自动匹配

#### 0.2.2 新增记录

1. 在列表页点击 **新增** 按钮
2. 在弹出的表单中填写必填字段（标记 ✅ 的字段）
3. 点击 **提交** 保存
4. 系统自动生成编号，返回列表页

#### 0.2.3 编辑记录

1. 在列表中找到需要编辑的记录
2. 点击 **编辑** 按钮
3. 修改字段内容
4. 填写变更原因（`change_reason`）
5. 点击 **保存**

> ⚠️ 部分状态下的记录不可编辑（如入库确认后、BOM发布后）。

#### 0.2.4 删除记录

1. 在列表中找到需要删除的记录
2. 点击 **删除** 按钮
3. 系统弹出确认对话框
4. 点击 **确认** 执行删除

> ⚠️ 删除操作不可逆，已关联其他数据的记录可能无法删除。

#### 0.2.5 分页浏览

- 列表底部显示分页控件
- 可切换每页显示条数（10/20/50/100）
- 点击页码跳转
- 显示总记录数和当前页码

#### 0.2.6 数据刷新

- 点击列表上方的 **刷新** 按钮重新加载数据
- 提交表单后列表自动刷新
- 浏览器 `F5` 刷新页面

### 0.3 打印操作

#### 0.3.1 打印入口

进入对应单据的详情页，点击 **打印** 按钮。

#### 0.3.2 打印预览

点击 **打印** 后，系统弹出打印预览窗口，可查看打印效果。

#### 0.3.3 6种打印模板

| 模板名称 | 对应单据 | 打印入口 |
|----------|----------|----------|
| 到货单打印 | 来料到货单 | 来料管理 → 到货单详情 |
| 来料检验报告打印 | 来料检验报告 | 来料管理 → 检验详情 |
| 原材料退货单打印 | 来料退货单 | 来料管理 → 退货单详情 |
| 出货单打印 | 出货单 | 出货管理 → 出货单详情 |
| 维修工单打印 | 维修工单 | 返厂维修 → 维修详情 |
| BOM打印 | BOM表 | BOM管理 → BOM详情 |

#### 0.3.4 打印常见问题

| 问题 | 解决方法 |
|------|----------|
| 打印内容不完整 | 调整浏览器打印设置中的边距 |
| 打印按钮灰色 | 当前单据状态不允许打印 |
| 打印机无响应 | 检查打印机连接和驱动 |

### 0.4 Excel导出

#### 0.4.1 列表页导出

1. 在列表页设置好筛选条件
2. 点击 **导出** 按钮
3. 系统生成Excel文件并自动下载
4. 打开下载的文件查看

#### 0.4.2 导出格式说明

- 文件格式：`.xlsx`
- 包含标题行、表头行、数据行
- 自动应用斑马纹、边框
- 金额列自动格式化为货币格式
- 支持自动筛选

### 0.5 Excel导入

#### 0.5.1 下载模板

1. 进入支持导入的模块（如BOM管理、商品SKU）
2. 点击 **导入** 按钮
3. 点击 **下载模板**
4. 保存模板文件到本地

#### 0.5.2 填写规范

- 按模板格式填写，不要修改列名
- 必填列不能为空
- 编码类字段需与系统中已有数据一致
- 日期格式：YYYY-MM-DD

#### 0.5.3 上传导入

1. 点击 **导入** → **选择文件**
2. 选择填写好的Excel文件
3. 点击 **上传**
4. 系统自动校验数据
5. 校验通过 → 导入成功

#### 0.5.4 导入结果查看

导入完成后，系统显示导入结果：
- 成功：N 条
- 失败：N 条（含失败原因）

#### 0.5.5 常见导入错误及解决

| 错误 | 原因 | 解决方法 |
|------|------|----------|
| 物料编码不存在 | 编码未在系统中创建 | 先在商品SKU中创建该物料 |
| 必填字段为空 | 模板中必填列未填写 | 补充必填字段 |
| 格式错误 | 日期/数字格式不正确 | 按模板格式修正 |
| 重复数据 | 导入数据与已有数据重复 | 检查重复项后重新导入 |

### 0.6 扫码操作

#### 0.6.1 扫码枪连接与使用

1. 将扫码枪通过USB连接电脑
2. 系统自动识别为键盘输入设备
3. 将光标定位到SN输入框
4. 扫描条码/二维码 → 自动填入SN并回车

#### 0.6.2 浏览器扫码

1. 点击SN输入框旁的扫码图标
2. 浏览器请求摄像头权限 → 点击 **允许**
3. 将条码/二维码对准摄像头
4. 识别成功后自动填入SN

#### 0.6.3 入库SN扫码录入

1. 进入入库管理 → 创建入库单
2. 将光标定位到SN输入框
3. 逐个扫描设备SN
4. 系统自动记录SN列表
5. 确认数量无误后提交

#### 0.6.4 出库SN扫码确认

1. 进入出库管理 → 创建出库单
2. 将光标定位到SN输入框
3. 逐个扫描待出库设备SN
4. 系统自动校验SN是否在库
5. 确认无误后提交

## 第1章 来料检/质量负责人操作指引

> ⚠️ **职责一句话**：来料检验把关 + 返厂设备诊断 + 维修质量检验
>
> 📊 **核心指标**：待检验数量、不合格率、返厂周转周期

### 1.1 每日/每周必做事项

**每日**：
- 查看待检验到货单，及时完成检验
- 查看待诊断返厂单，及时完成诊断
- 查看待质检返厂单，及时完成质量检验

**每周**：
- 统计本周不合格率，分析趋势
- 统计返厂周转周期
- 检查待报废设备，提交报废申请

### 1.2 来料管理（主线A）

#### 1.2.1 查看待检验到货单

1. 进入来料管理 → 列表页
2. 筛选状态为 `PENDING_INSPECTION`（待检验）
3. 查看待检验到货单列表
4. 点击到货单号查看详情

#### 1.2.2 录入检验报告

1. 在待检验到货单列表中，点击 **检验** 按钮
2. 填写检验报告：
   - 抽样数量（`sample_qty`）
   - 不良数量（`defect_qty`）
   - 不良描述（`defect_description`）
3. 选择检验结果（`result`）：
   - **合格**（`ACCEPTED`）：全部合格
   - **让步接收**（`CONCESSION_ACCEPTED`）：有瑕疵但可接受
   - **不合格**（`REJECTED`）：拒收退货
4. 填写变更原因
5. 点击 **提交** → 到货单状态变为 `INSPECTED`
6. 可点击 **打印** 打印检验报告

#### 1.2.3 处理不合格退货

1. 检验结果为不合格的到货单，状态变为 `REJECTED`
2. 仓库管理员确认退货后，可在退货单列表中查看
3. 关注退货单状态，确认退货完成

#### 1.2.4 导入导出到货数据

1. 在来料管理列表页 → 点击 **导出** 导出到货数据
2. BOM导入见第3章

### 1.3 返厂维修（主线B）

#### 1.3.1 查看返厂退货单

1. 进入返厂维修 → 列表页
2. 按状态筛选：
   - `PENDING_DIAGNOSIS`：待诊断
   - `DIAGNOSED`：待分配
   - `REPAIRED`：待质检
3. 点击返厂单号查看详情

#### 1.3.2 填写诊断报告

1. 在待诊断返厂单列表中，点击 **诊断** 按钮
2. 填写诊断报告（DG编号）：
   - 故障描述（`fault_description`）
   - 诊断结果（`diagnosis_result`）：`REPAIRABLE`
   - 维修方案（`repair_plan`）
3. 填写变更原因
4. 点击 **提交** → 返厂单状态变为 `DIAGNOSED`

#### 1.3.3 分配维修任务

1. 在已诊断返厂单列表中，点击 **分配** 按钮
2. 选择分配类型（`assign_type`）：
   - **生产**（`PRODUCTION`）：外观问题，分配给生产主管
   - **测试**（`TEST`）：功能问题，分配给测试工程师
   - **报废**（`SCRAP`）：判定报废，进入审批流程
3. 选择分配人（`assigned_to`）
4. 填写分配原因（`assign_reason`）
5. 点击 **提交** → 返厂单状态变为 `ASSIGNED`

#### 1.3.4 任务转交

1. 在已分配返厂单中 → 点击 **转交**
2. 选择新的分配人
3. 填写转交原因
4. 点击 **提交**

#### 1.3.5 维修后质量检验

1. 在已修复返厂单列表中（`REPAIRED` 状态），点击 **质检** 按钮
2. 填写检验描述（`check_description`）
3. 选择检验结果（`check_result`）：
   - **通过**（`PASS`）：进入入库流程
   - **不通过**（`FAIL`）：退回维修
4. 填写变更原因
5. 点击 **提交** → PASS进入 `QUALITY_CHECK`，FAIL退回 `REPAIRING`

#### 1.3.6 报废申请

1. 分配任务时选择分配类型为 `SCRAP`（报废）
2. 系统自动创建报废审批单（BF编号）
3. 填写报废原因
4. 等待总经理审批

### 1.4 出货管理（主线C）

#### 1.4.1 查看出货单

1. 进入出货管理 → 列表页
2. 按日期、物流供应商等条件筛选
3. 点击出货单号查看详情

#### 1.4.2 出货前质量确认

1. 在出货单详情中查看SN列表
2. 确认出货设备质量状态
3. 如有问题，通知仓库管理员暂缓出货

### 1.5 常见错误与预防

| 常见错误 | 后果 | 预防措施 |
|----------|------|----------|
| 检验结果选错 | 不合格物料入库/合格物料退货 | 提交前仔细核对检验结果 |
| 诊断结果不准确 | 分配错误，维修效率低 | 详细描述故障，附照片 |
| 分配类型选错 | 任务分配给错误角色 | 确认分配类型后再提交 |
| 质检不仔细 | 不合格设备流入零成本仓 | 逐项检查维修质量 |
| 忘记填写变更原因 | 提交失败 | 变更原因必填 |

## 第2章 仓库管理员操作指引

> ⚠️ **职责一句话**：所有物料入库/出库/库存管理 + 4条主线的仓管环节
>
> 📊 **核心指标**：在库数量、待审核数量、库存变动趋势

### 2.1 每日/每周必做事项

**每日**：
- 查看待入库确认的到货单（`ACCEPTED` 状态）
- 查看待入库的返厂单（`QUALITY_CHECK` 状态）
- 查看待出货单
- 检查库存预警

**每周**：
- 导出库存报表
- 核对库存实物与系统数据
- 检查待退货单

### 2.2 入库管理

#### 2.2.1 采购入库

1. 进入来料管理 → 筛选 `ACCEPTED` 状态的到货单
2. 点击 **入库确认** 按钮
3. 确认入库信息（物料、数量、仓库类型）
4. 录入SN（如需要）
5. 填写变更原因
6. 点击 **确认入库** → 到货单状态变为 `WAREHOUSED`，物料进入原材料仓

#### 2.2.2 非采购入库

1. 进入入库管理 → 点击 **新增入库单**
2. 填写入库物料、数量、仓库类型
3. 录入SN
4. 点击 **提交** → 进入待审核

#### 2.2.3 SN录入方式

- **单个录入**：在SN输入框中逐个输入，回车确认
- **批量粘贴**：每行一个SN，粘贴到SN输入框
- **扫码录入**：使用扫码枪逐个扫描

#### 2.2.4 入库审核

1. 入库单创建后进入待审核状态
2. 具有审核权限的角色审核通过
3. 审核通过后库存更新

#### 2.2.5 入库单查询与导出

1. 进入入库管理 → 列表页
2. 按日期、仓库类型、入库类型筛选
3. 点击 **导出** 导出入库数据

### 2.3 出库管理

#### 2.3.1 11种出库类型选择指南

| 出库类型 | 代码 | 使用场景 | 对应退回类型 |
|----------|------|----------|-------------|
| 售出-线上 | `SOLD` | 正常销售发货 | RETURNED_FROM_SALE |
| 售出-线下 | `SOLD_OFFLINE` | 线下门店销售 | RETURNED_FROM_SOLD_OFFLINE |
| 准售出 | `PRESOLD` | 预售/待确认销售 | RETURNED_FROM_PRESOLD |
| 赠送 | `GIFTED` | 免费赠送 | RETURNED_FROM_GIFT |
| 报废 | `SCRAPPED` | 设备报废处理 | RETURNED_FROM_SCRAPPED |
| 研发 | `RND` | 研发领用 | RETURNED_FROM_RND |
| 样机 | `SAMPLE` | 样机展示 | RETURNED_FROM_SAMPLE |
| 试用 | `TRIAL` | 客户试用 | RETURNED_FROM_TRIAL |
| 维修 | `REPAIR` | 维修领用 | RETURNED_FROM_REPAIR |
| 部门采购 | `DEPT_PROCUREMENT` | 内部部门采购 | RETURNED_FROM_DEPT_PROCUREMENT |
| 借用 | `BORROWED` | 临时借用 | RETURNED_FROM_BORROW |

#### 2.3.2 出库单创建与提交

1. 进入出库管理 → 点击 **新增出库单**
2. 选择出库类型（参考上表）
3. 选择出库物料、填写数量
4. 录入SN（扫码或手动输入）
5. 填写变更原因
6. 点击 **提交** → 出库单进入待审核

#### 2.3.3 拣货确认

1. 在出库单详情中查看SN列表
2. 按照SN列表逐项拣货
3. 确认实物与系统一致
4. 点击 **拣货确认**

#### 2.3.4 出库审核

1. 拣货确认后，出库单进入待审核
2. 审核通过 → 库存扣减，SN状态变更
3. 审核不通过 → 退回修改

#### 2.3.5 出库单查询与导出

1. 进入出库管理 → 列表页
2. 按出库类型、日期、物料筛选
3. 点击 **导出** 导出出库数据

### 2.4 来料管理（主线A）

#### 2.4.1 到货单登记

1. 进入来料管理 → 点击 **新增到货单**
2. 选择供应商、物料SKU
3. 填写批次号、到货数量、到货日期
4. 点击 **提交** → 到货单状态变为 `PENDING_INSPECTION`
5. 可打印到货单

#### 2.4.2 检验合格后入库确认

1. 筛选 `ACCEPTED` 状态的到货单
2. 点击 **入库确认**
3. 确认信息 → 点击 **确认入库**
4. 到货单状态变为 `WAREHOUSED`

### 2.5 返厂维修（主线B）

#### 2.5.1 维修后入库确认

1. 进入返厂维修 → 筛选 `QUALITY_CHECK` 状态
2. 点击 **入库** 按钮
3. 确认新SN、选择仓库类型（默认 `ZERO_COST_FINISHED`）
4. 点击 **确认入库** → 返厂单状态变为 `WAREHOUSED`

#### 2.5.2 再出货操作

1. 筛选 `WAREHOUSED` 状态的返厂单
2. 点击 **再出货** 按钮
3. 填写收货人、出货日期
4. 点击 **提交** → 生成再出货单（RH编号），返厂单状态变为 `RESHIPPED`

#### 2.5.3 报废出库

1. 报废审批通过后，返厂单状态变为 `SCRAPPED`
2. 系统自动创建报废出库单
3. 确认后库存扣减

### 2.6 出货管理（主线C）

#### 2.6.1 出货单创建

1. 进入出货管理 → 点击 **新增出货单**
2. 选择物料SKU（系统自动带出物料编码、名称、规格）
3. 添加SN列表
4. 选择发货日期

#### 2.6.2 添加SN列表

1. 逐个输入SN或批量粘贴
2. 系统自动校验SN是否在库
3. 系统自动计算数量
4. 支持扫码录入

#### 2.6.3 填写物流信息

1. 填写收货地址

- 旧SN状态变为 `REPLACED`，指向新SN

- 通过SN可追溯完整维修历史

#### 4.4.4 填写维修用料与耗时

- **维修用料**（`materials_used`）：列出维修中使用的物料，如"主板×1, 排线×2"

## 第6章 常见问题FAQ

### 6.1 通用问题

**Q：忘记了密码怎么办？**
A：联系管理员（`ADMIN` 角色）重置密码。登录后请立即修改密码。

**Q：登录时提示"账号已锁定"怎么办？**
A：连续5次密码错误会导致账号临时锁定，联系管理员解锁。

**Q：为什么我看到的菜单和别人不一样？**
A：系统根据角色显示不同菜单，不同角色有不同的功能权限。

**Q：如何导出数据？**
A：在列表页点击 **导出** 按钮，系统自动下载Excel文件。

**Q：扫码枪怎么用？**
A：USB连接电脑后，将光标定位到SN输入框，直接扫描条码即可。

### 6.2 来料检/质量问题

**Q：检验结果选错了怎么办？**
A：联系管理员或通过编辑功能修改检验结果，需填写变更原因。

**Q：让步接收和合格入库有什么区别？**
A：在库存层面无区别，仅在检验报告中记录差异。让步接收表示有瑕疵但可接受。

**Q：诊断结果只有"可维修"一个选项吗？**
A：是的，当前诊断结果统一为 `REPAIRABLE`。如需判定报废，在分配任务时选择 `SCRAP`。

**Q：质检不通过后返厂单会怎样？**
A：返厂单自动退回 `REPAIRING` 状态，需重新维修。

### 6.3 仓库问题

**Q：入库确认后还能撤销吗？**
A：不能。入库确认后库存立即生效，不可撤销。请确认无误后再操作。

**Q：出库类型选错了怎么办？**
A：联系管理员修改，需填写变更原因。建议参考第2章2.3.1选择指南。

**Q：SN录入错误怎么办？**
A：建议使用扫码枪减少手动输入错误。已录入的SN需要联系管理员修改。

**Q：零成本仓和普通成品仓有什么区别？**
A：零成本仓存放维修完成的设备，不计入库存成本。普通成品仓存放正常采购或生产的成品。

### 6.4 生产问题

**Q：BOM发布后还能修改吗？**
A：不能。需创建新版本修改。旧版本可标记为 `DISCONTINUED`。

**Q：物料齐套检查显示缺料怎么办？**
A：查看缺料明细，根据缺料清单安排采购。采购入库后点击 **标记齐套**。

**Q：BOM导入失败怎么办？**
A：检查物料编码是否已在系统中存在。详见第0章0.5.5常见导入错误。

**Q：生产任务完成后物料会自动扣减吗？**
A：是的，生产任务完成后系统自动扣减原材料库存。

### 6.5 测试问题

**Q：新SN重复了怎么办？**
A：系统会自动校验并拒绝重复SN。请更换新SN，或在库存中搜索确认。

**Q：维修工单可以修改吗？**
A：提交后如需修改，联系管理员处理，需填写变更原因。

**Q：维修用料必须填写吗？**
A：建议填写，用于维修成本核算和效率分析。如确实没有用料，可填"无"。

### 6.6 管理问题

**Q：报废审批通过后还能撤销吗？**
A：不能。审批通过后设备状态变为 `SCRAPPED`，不可撤销。

**Q：如何查看某个用户的所有操作记录？**
A：进入审计日志，按操作人筛选，可查看该用户的所有操作。

**Q：可以删除用户吗？**
A：建议禁用而非删除，保留用户历史操作记录。

**Q：系统数据如何备份？**
A：通过MySQL定时备份（mysqldump），建议每日全量备份。
