### 2.5 Capacitor 专项检查（二期新增）

> **设计原则**：Capacitor 打包现有 Web = 零额外开发。App 只放"现场高频、需扫码/拍照"的操作，复杂报表/BOM编辑/批量导入导出不放。

#### 2.5.1 架构设计

```
┌─────────────────────────────────────────────┐
│              Android APK                     │
│  ┌───────────────────────────────────────┐  │
│  │         Capacitor WebView              │  │
│  │  ┌─────────────────────────────────┐  │  │
│  │  │    Vue 3 + Element Plus SPA     │  │  │
│  │  │    (Vite 构建 → dist/)           │  │  │
│  │  │                                 │  │  │
│  │  │  axios → /api/v1/*              │  │  │
│  │  └──────────────┬──────────────────┘  │  │
│  └─────────────────┼─────────────────────┘  │
└────────────────────┼────────────────────────┘
                     │ HTTP (cleartext)
                     ▼
         ┌───────────────────┐
         │  FastAPI Backend  │
         │  (port 8000)      │
         └───────────────────┘
```

**方案决策：打包静态资源（方案A）**

| 方案 | 配置 | 优点 | 缺点 | 选择 |
|------|------|------|------|:---:|
| A. 打包静态资源 | `webDir: "dist"`，不配 `server.url` | 离线可用，启动快 | 每次更新需重新打包 | ✅ |
| B. 加载服务器页面 | 配 `server.url: "http://IP:8080"` | 更新即生效，无需重打包 | 必须联网，启动稍慢 | ❌ |

> 理由：内网环境更新不频繁；离线可用，现场信号不好时也能操作；更新时重新发 APK，员工覆盖安装即可。

#### 4.8.1 端口可用性检查（前置步 — v2.12 新增）

> **触发条件**：执行"完整检测清单"时，作为前置步自动执行。
> **脚本路径**：`scripts/check_port.ps1`

| # | 检查项 | 命令 | 通过标准 |
|---|--------|------|---------|
| 1 | 前端端口 5173 未被占用 | `powershell -File scripts/check_port.ps1 -Port 5173` | 输出 `✅ 端口 5173 可用` |
| 2 | 后端端口 8000 未被占用 | `powershell -File scripts/check_port.ps1 -Port 8000` | 输出 `✅ 端口 8000 可用` |
| 3 | 若端口被占用，输出占用进程信息 | 同上 | 输出进程名 + PID + 释放命令 |

**脚本内容**：`scripts/check_port.ps1`

```powershell
param([int]$Port = 5173)

$ErrorActionPreference = "Stop"

$conn = Get-NetTCPConnection -LocalPort $Port -ErrorAction SilentlyContinue
if ($conn) {
    Write-Host "  ❌ 端口 $Port 已被占用" -ForegroundColor Red
    Write-Host "  进程名: $((Get-Process -Id $conn.OwningProcess).ProcessName)" -ForegroundColor Yellow
    Write-Host "  PID: $($conn.OwningProcess)" -ForegroundColor Yellow
    Write-Host ""
    Write-Host "  释放端口: taskkill /PID $($conn.OwningProcess) [/F]" -ForegroundColor Cyan
    exit 1
}
Write-Host "  ✅ 端口 $Port 可用" -ForegroundColor Green
exit 0
```

**背景**：Vite 默认 `strictPort: false`，端口被占时静默漂移到 5174/5175/...，而后端 CORS 通过 `allow_origin_regex` 匹配任意开发端口，确保漂移不影响功能。端口检查脚本用于启动前确认默认端口状态，避免意外漂移。
